GM-86 · feature/GM-86-place-extraction-queue

로컬 Postman 워커 실행 지원

PR 머지 후 동료가 GCP Cloud Tasks를 건드리지 않고 로컬에서 job 생성부터 워커 처리, 결과 조회까지 검증할 수 있게 하는 변경입니다.

검증 완료

결론

bun run start:local은 자동으로 APP_ENV=local과 CLOUD_TASKS_MODE=local을 설정합니다. 이 모드에서는 실제 Cloud Tasks enqueue를 하지 않고, Postman에서 로컬 워커를 직접 호출할 수 있습니다.

운영에서는 APP_ENV=prod, NODE_ENV=production, CLOUD_TASKS_MODE=cloud 조합만 허용됩니다. 따라서 production의 Cloud Tasks OIDC 인증 경로는 유지됩니다.

동료의 Postman 실행 흐름

1. 서버 실행bun run start:local
2. job 생성POST /api/v1/place/places
3. 워커 실행POST /internal/.../process
4. 결과 조회GET /api/v1/place/jobs/:jobId

워커 요청

POST http://localhost:3000/internal/place/jobs/{jobId}/process

local + non-production 모드에서만 OIDC guard가 우회됩니다. 운영에서는 Cloud Tasks OIDC 토큰이 계속 필요합니다.
